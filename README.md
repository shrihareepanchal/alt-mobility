# Alt Mobility – Data Analyst Assignment

## 🔍 Overview

This project solves a real-world data analysis challenge for Alt Mobility, focusing on EV fleet orders and payments.

## 📁 Files Used

- `customer_orders.csv`
- `payments.csv`

## 📌 Tasks Completed

1. **Order and Sales Analysis** – Revenue trends and top customers
2. **Customer Analysis** – Repeat orders, average engagement, active users
3. **Payment Status Analysis** – Success/failure rate and trends
4. **Order Details Report** – Combined orders and payments for reporting
5. **Customer Retention Visualization** – Cohort analysis with heatmap

## 💻 Tools

- Python (pandas, SQLite, matplotlib, seaborn)
- SQL for core queries
- Jupyter Notebook or Python scripts

## 📊 Visualizations

- Retention heatmap showing how many users returned month-over-month

## 📈 Key Insights

- High delivery and payment success rates
- Strong repeat ordering behavior
- Opportunities to improve long-term retention
